# Learn Leadership in the Age of AI with Phoebe

Organising for AI: six 45-minute sessions for the executives deciding a company-wide workforce
strategy. AI changes tasks, not job titles, so the organisation is redesigned from the task up,
with the review load, the junior pipeline and the board's business case in view.

- Running case: Marlowe Group, a constructed 4,000-person professional-services firm.
- Bench (session 4): real O*NET 31.0 task statements and ratings (USDOL/ETA, CC BY 4.0) joined to
  the task-level exposure labels released with Eloundou, Manning, Mishkin and Rock (2023, MIT),
  computed in the browser from the naive exposed share to a board range, with an anti-lever and a
  break button.
- Static site: open `index.html`. No build step.
